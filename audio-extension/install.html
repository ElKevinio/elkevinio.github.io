Audio-Erweiterung einrichten

Direkt von dieser Webseite, ohne Store. Der Download installiert noch nichts: Chrome und Edge benötigen einmalig eine manuelle Einrichtung auf deinem Desktop.

Erweiterung herunterladen · ZIP

Einmal installieren

  1. ZIP herunterladen und entpacken. Den Ordner vinyl-equalizer dauerhaft auf deinem Computer behalten.
  2. In Chrome chrome://extensions öffnen; in Edge edge://extensions. Diese Adresse in die Adressleiste kopieren.
  3. Entwicklermodus aktivieren und Entpackte Erweiterung laden wählen.
  4. Den entpackten Ordner vinyl-equalizer mit der Datei manifest.json auswählen.
  5. Die Vinyl-Seite neu laden und die Erweiterung über das Puzzle-Symbol des Browsers anheften.

Equalizer starten

  1. Die Vinyl-Seite in Chrome oder Edge öffnen und Musik starten.
  2. Einmal oben im Browser auf Vinyl · Audio-Equalizer klicken. Damit erlaubst du die Analyse dieses Tabs.
  3. Die Seite erkennt die laufende Verbindung automatisch. Der Equalizer folgt jetzt dem Tab-Audio.

Ein erneuter Klick auf das Erweiterungssymbol oder „Audio-Verbindung trennen“ auf der Webseite stoppt die Analyse.

Der Ton bleibt hörbar. Die Erweiterung speichert keine Aufnahme und sendet kein Audio an einen Server. Sie gibt nur 32 Frequenzwerte an den Vinyl-Tab weiter. Die normale Bildschirmfreigabe entfällt; der Browser kann trotzdem einen Aufnahmeindikator anzeigen. Nach Browserneustarts, einem Neuladen der Seite oder einer beendeten Freigabe ist ein neuer Klick nötig.

Für Desktop-Chrome ab Version 116 und entsprechend aktuelle Edge-Versionen. Nicht für Safari, mobile Browser oder den eingebetteten Codex-Browser. Geschützte Medien können vom Browser stumm geliefert werden. Updates: neue ZIP entpacken und die Erweiterung auf der Erweiterungsseite neu laden.
